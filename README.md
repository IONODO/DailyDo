A DAILY task management app meant for starting a day with a clean slate

[!NOTE]
APK/version launch is slated for later once features are finally done to my liking.

### What makes it different
The app isnt just a large todo-list storage, it shows on what you NEED to do that day- Newly added tasks, recurring tasks, task due for the next day, all necessary information.
Everything else away from view. (the calendar can be used to see ALL tasks)
Tasks delete 3 days after completion on their own (option to change this duration will be added later)
and for EACH task you can track time, or simply use the timer like a regular one
